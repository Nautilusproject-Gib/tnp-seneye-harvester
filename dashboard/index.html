In-situ samples

Readings come from Seneye monitors in the nursery sumps, polled from the Seneye cloud API and stored by the TNP harvester. Each sump serves the tanks listed on its panel, so a reading describes the water shared by those tanks rather than any single tank.

Working ranges shown on the charts are the nursery's own operating set points, not published tolerances for Posidonia oceanica.
